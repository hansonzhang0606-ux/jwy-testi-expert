> 全程约 10 分钟。**遇到问题请勿自行改文件**，把现象 + 截图发回给 Hanson。
> 配套文档：《泾渭云测试专家-安装使用手册.md》（步骤细节以手册为准）。

## 0. 开始前（3 个动作）

- [ ] **完全退出 WorkBuddy**（托盘图标右键 → 退出，不是关窗口）。
      脚本会检测进程并提示，但先退出最稳。
- [ ] **拉最新仓库**（不要用手上旧包，旧版安装脚本有已知 bug）：
      ```bash
      git clone https://github.com/hansonzhang0606-ux/jwy-testi-expert.git
      # 已 clone 过则：git pull
      ```
- [ ] 记下仓库版本，便于反馈时定位：
      ```bash
      git log --oneline -1
      ```

## 1. 运行一键安装脚本

进入 `dist\jingweiyun-testing-expert` 目录，右键 `install.ps1` → **「使用 PowerShell 运行」**。

**预期输出**：6 步全部有中文提示，最后出现「安装完成 / 请重启 WorkBuddy」。

- [ ] 第 4 步显示的是**覆盖式复制**（不会删除已有目录）
- [ ] 第 6 步定时任务：显示「已创建」或「已存在」；若提示**找不到 python** → 属正常，不影响专家使用，勾「跳过」并备注
- [ ] 结尾出现 `marketplace.json 校验通过`（说明注册真的写进去了）

**异常对照表**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 窗口一闪而过 / 直接报错「字符串缺少终止符」 | 拿到的包是旧版（无 BOM） | 重新 `git pull` 再运行 |
| 提示「检测到 WorkBuddy 正在运行」 | 没退干净 | 托盘退出后重跑 |
| 提示权限不足 | 非管理员 | 定时任务可跳过，其余不受影响 |
| 中文显示成乱码 | 同上，旧版编码问题 | 重新 `git pull` |

## 4. 配置 MySQL（工时数据入库用）

首次会话时，AI 会**自动生成空模板 + 字段说明**，无需你敲命令：

- [ ] `%USERPROFILE%\.workbuddy\data\time-tracking\泾渭云\mysql_config.json` 已生成（内容为待填写模板）
- [ ] 同目录 `mysql_config.notes.md` 已生成（逐字段说明去哪取值）
- [ ] 按说明填写 host / port / user / password，找 Hanson 或管理员获取真实值

> 🔒 **不要把密码直接发在对话里给 AI**。填文件即可。

- [ ] 填完后让 AI 跑一次连通性预检：
      ```bash
      python scripts/sync_to_mysql.py --biz-line 泾渭云 --dry-run
      ```
      预期：显示读取到本地记录条数，**无报错**。没有记录也属正常（新机器本来就是空的）。
